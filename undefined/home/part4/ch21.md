# 21장 기억을 쓰고 지우고 다시 쓸 수 있는가

**기억을 쓰고 지우고 다시 쓸 수 있는가**

> 상관된 표지가 기능적 기억의 원인이라면 같은 유전자좌에서 표지를 쓰고 지우고 다시 쓸 때 기능도 가역해야 한다.

## 기존 학계의 출발점

CRISPR 기반 후성유전체 편집은 DNA 서열을 바꾸지 않고 methylation나 히스톤 상태를 조절한다. 양방향 편집은 표지 사이의 위계와 문맥의존성을 드러낸다.

## WRRA의 재구성

선언모형의 표지량은 0.5050에서 삭제 후 0.0008, 재쓰기 후 0.5090으로 변했고 rescue는 1.008이었다. 이 값은 실험결과가 아니라 사전등록 문턱을 만드는 시뮬레이션이다.

## 비교해 읽기

write-erase-rewrite는 표지와 기능의 상관을 인과성으로 바꾸는 가장 직관적인 가역실험이다. 그러나 편집도구가 같은 자리에 결합하는 행위 자체가 전사를 바꿀 수 있으므로 촉매불활성 effector와 sham 대조가 필요하다. 삭제 뒤 세포가 죽고 남은 세포만 분석되는 선택효과도 차단해야 한다.

가장 강한 결과는 같은 barcode 계보에서 표지, RNA, 단백질과 기능이 write에서 변하고 erase에서 돌아오며 rewrite에서 다시 복구되는 것이다. 조작을 제거한 뒤 최소 세 번 분열해도 방향이 유지되어야 기억의 계보상속을 말할 수 있다. 표지만 가역하고 기능이 움직이지 않으면 그 표지는 원인보다 표식일 가능성이 높다.

> 해석과 예측의 경계 실험에서는 비표적 가이드, 촉매불활성 effector, off-target, 독성, 선택편향을 차단하고 최소 3회 분열 뒤 기능복구를 확인해야 한다.

## 연구 내용과 검증 결과

## Life Model VIII: 후성유전 기억의 쓰기·삭제·복원

Life VIII은 상관에서 인과로 넘어가는 모델이다. 유전체 G와 현재 환경 U를 유지한 채 후보 기억상태 Z만 선택적으로 기록·삭제·재기록하여 표현형의 가역을 요구한다. 한 방향의 발현변화만으로는 off-target, 독성, 선택 또는 일반적 스트레스를 배제할 수 없다.

G′=G, U′=U, Z′≠Z ⇒ Y′=R\_bio(G,Z′,U) (60)

Z₀ →write Z₁ →erase Z₀′ →rewrite Z₁′; Y₀ → Y₁ → Y₀′ → Y₁′ (61)

표 23. Life Model VIII의 인과성 사다리.

| **단계** | **필수 관측**                 | **실패 해석**                |
| ------ | ------------------------- | ------------------------ |
| 기록     | 표적 Z 변화와 Y 변화             | 효과 없음 또는 locus 문맥 부적합    |
| 삭제     | Z와 Y가 기준선 방향으로 복귀         | 표지가 결과이거나 기억이 분산됨        |
| 재기록    | 같은 locus에서 Z와 Y 재현        | 첫 변화가 선택·off-target일 가능성 |
| 다세대 유지 | 편집기 제거 뒤 계보에서 기능 지속       | 일시적 전사활성일 뿐 기억 아님        |
| 직교 재현  | 다른 효과기·gRNA·clone에서 같은 방향 | 도구 특이효과                  |

핵심 endpoint는 단일 표지의 존재가 아니라 분화기능, 재자극 반응, 계보 유지와 rescue다. 표적 편집 플랫폼이 chromatin mark의 문맥의존적 인과효과를 보여주었으므로 \[37,38], WRRA의 추가 요구는 편집기 제거, 가역 rescue, sister-lineage 통제 및 다세대 기능을 하나의 사전등록 계약으로 결합하는 데 있다.

### 안전경계

기능 회복과 함께 세포정체성·유전체 안정성·종양성·가역성을 공동 판정한다.

부분 재프로그래밍에서 clock 감소를 기능적 회춘으로 자동 승격하지 않는다.

생식세포·배아의 유전 가능한 편집은 본 연구범위에서 제외한다.

하나의 안전 gate라도 실패하면 임상적 기억교정으로 판정하지 않는다.

Release = Function ∧ Identity ∧ Genome stability ∧ No tumorigenicity ∧ Controllability (62)

## 트랙 4: 후성유전 기억의 쓰기–삭제–재쓰기

상관된 표지가 기능적 기억의 원인인지 확인하려면 같은 표적에서 표지를 쓰고, 삭제하고, 다시 써서 기능이 가역하는지 측정해야 한다. 선언 모형의 표지량은 0.5050→0.0008→0.5090으로 변했고, 재쓰기 후 복구율은 1.008이었다.

Rescue = (M\_rewrite−M\_erase)/(M\_write−M\_erase) = 1.008 (77)

표 36. 인과적 가역 편집의 사전등록 계약.

| ------ | -------------------------------------------------- |

| 순서     | write→washout→erase→washout→rewrite; 각 단계의 편집효율 확인 |
| 결과     | 표지, RNA, 단백질, 기능, 세포생존, 계보별 최소 3회 분열 지속            |
| 인과 판정  | 쓰기와 재쓰기가 방향성 기능변화를 만들고 삭제가 역전하며 rescue 문턱 충족       |
| 기각     | 표지만 가역하고 기능은 불변, 또는 off-target·선택으로 설명됨            |
