# 16장 최초 생명은 언제 시작되는가

**최초 생명은 언제 시작되는가**

> 최초 생명은 LUCA와 다르다. LUCA는 이미 진화한 공통조상이고, 최초 생명은 화학반응이 유전 가능한 기능계통으로 넘어간 가장 이른 경계다.

## 기존 학계의 출발점

RNA world, 대사우선, 막우선과 혼합모형은 각각 복제, 촉매, 에너지와 구획의 선행관계를 다르게 본다. 실험은 각 모듈의 가능성을 보여 주지만 하나의 완전자율 계통은 아직 없다.

## WRRA의 재구성

기준선에서 R\_life=2Kf^L, 임계 정확도 f\_c=(2K)^(-1/L)로 둔다. 이 식은 선언된 독립오류·이분열 가정 아래 정확하지만 최초 분자서열이나 장소를 정하지 않는다.

## 비교해 읽기

최초 생명 후보를 특정 화학물질 하나로 고정하면 실제 전이의 구조를 놓칠 수 있다. 중요한 것은 RNA인지 peptide인지의 이름보다 정보가 복제되고 오류가 축적되며, 촉매가 실행을 돕고, 경계가 구성요소를 함께 유지하고, 에너지가 다음 주기를 가능하게 하는 결합이다.

R\_life>1은 생명의 철학적 정의 전체를 대신하지 않는다. 다만 실험에서 계통이 초임계인지 판단하는 최소한의 운영기준을 제공한다. 후손 수만 세지 않고 필수기능을 유지한 후손만 K에 포함해야 하며, 환경이 제공한 기능을 별도의 자율성 지수로 보고해야 한다.

> 해석과 예측의 경계 RNA 유사 중합체, peptide 촉매와 지방산 경계는 유력한 비유일 후보다. 후보의 개연성과 역사적 실재를 구분하고, 자기유지 계통의 실험적 시연을 최종 문턱으로 남긴다.

## 연구 내용과 검증 결과

## 최초 생명: 화학에서 유전 가능한 계통으로

최초 생명은 LUCA가 아니다. 화학적 증식, 경계가 있는 원시세포, 살아 있는 계통, 자율 세포, LUCA는 서로 다른 단계다. WRRA의 목표는 역사적으로 지워진 단 하나의 최초 개체를 복원하는 것이 아니라, 화학이 처음으로 생명적 계통이 되는 실행 경계를 정의하는 것이다.

| **대상**         | **운영적 정의**              | **생명 판정** |
| -------------- | ----------------------- | --------- |
| 화학적 reproducer | 물질 패턴의 성장·재현            | 불충분       |
| protocell      | 성장·분열 가능한 경계화 화학계       | 필요 후보     |
| 최초 살아 있는 계통    | 유전 가능한 기능 폐쇄와 R\_life>1 | WRRA 경계   |
| 자율 세포          | 대부분의 renderer 기능을 내부 재생 | 후대 단계     |
| LUCA           | 현생 세포생명의 마지막 공통조상 집단    | 최초 생명 아님  |

### 다섯 소유자와 정확한 임계식

| **소유자** | **최소 과업**       | **실패 형태**     |
| ------- | --------------- | ------------- |
| 정보      | 기능 서열·조성의 보존    | 누적 유전 없음      |
| 촉매      | 폐쇄 지지 반응 가속     | 희석이 생산 초과     |
| 경계      | 농축과 선택 가능한 개체성  | 성분 분산         |
| 에너지     | 평형에서 벗어난 반응 유지  | 불활성화          |
| 분배      | 충분한 기능을 후손에게 전달 | 성장은 있으나 계통 없음 |

표 13. 최초 생명의 다섯 최소 소유자.

q = Kfᴸ, R\_life = 2Kfᴸ (31)

f\_c(L,K) = (2K)^(-1/L), K > 1/2 (32)

K는 경계 연속성·촉매 폐쇄·에너지 결합·분배 유지 등 비복제 조건의 공동 성공확률이다. K≤1/2이면 완벽한 서열 복사도 두 딸 과정의 기대값을 1보다 크게 만들 수 없다. 즉 유전정보만 개선해서는 자주 실패하는 renderer를 보상할 수 없다.

| ---------------- | -------- |

| 촉매 폐쇄            | 0.85     |
| 에너지 결합           | 0.90     |
| 분배 유지            | 0.90     |
| K                | 0.61965  |
| L=100의 f\_c      | 0.997856 |
| f=0.999의 R\_life | 1.121    |

### 환경 renderer와 후보 구조

FIRST LIFE = PROTOCELL + LOCAL GEOCHEMICAL RENDERER (33)

습윤–건조, 온도 진동, 광·방사, 광물표면, 산화환원 기울기는 후대 세포가 내부화한 농축·활성화·분리·교정 기능 일부를 대신했을 수 있다. 환경 자체가 살아 있다는 뜻은 아니다. 내부 정보가 기능적 후손 수를 바꾸는 경계화 계통이 선택 단위다.

L₀ = RNA-like information + short peptides + fatty-acid boundary + energy cycle (34)

현재 증거와 가장 잘 양립하는 후보는 벌거벗은 DNA 세포보다 RNA 유사 정보고분자, 짧은 촉매 peptide, 투과성 지방산 구획, 활성화 단량체와 반복 환경주기의 결합이다. 초기에는 누출·융합·수평교환이 잦은 이질적 원시세포 집단이 임계점을 여러 번 넘었을 가능성이 있다.

πₜ₊₁(y) ∝ ∫ B(y|x)πₜ(x)dx (35)

스펙트럼 반경이 1보다 큰 계통은 하위임계 계통보다 후대 분포에 더 많이 남는다. 여기서 선택은 선택하는 주체를 추가하는 말이 아니라, 이미 존재하는 변이들의 차등 증식을 요약한다.

## Life Model X: 최초 생명의 최소 폐쇄조건 재정식화

제8절의 최초 생명모형을 후성유전 기억 연구와 다시 연결한다. 복제분자가 존재하거나 소포가 한 번 분열했다고 곧바로 살아 있는 계통이 되는 것은 아니다. 최소 생명은 경계, 자원획득, 정보복제, 기능실행, 오류복구, 경계 재생산이 다음 세대에서 다시 실행될 만큼 닫혀야 한다.

L\_min = {B, S, R, P, E, C} (66)

B는 경계, S는 복제 가능한 정보원, R은 정보해독 관계, P는 촉매·기능고분자, E는 에너지·물질흐름, C는 전체 순환의 재생산 폐쇄다. 이를 외부가 대신하는 정도를 숨기지 않기 위해 자율폐쇄율을 정의한다.

Λ\_auto = (내부에서 재생산되는 필수 연산)/(전체 필수 연산), 0≤Λ\_auto≤1 (67)

표 25. Life Model X의 최소 생명 감사.

| **소유자** | **최소 과업**        | **한 세대 성공만으로 부족한 이유**    |
| ------- | ---------------- | ------------------------ |
| 경계 B    | 농축·개체성·분열 뒤 재봉합  | 외부 소포 공급에 의존할 수 있음       |
| 정보 S    | 기능차이의 유전         | 복사만 되고 기능과 연결되지 않을 수 있음  |
| 해독 R    | 정보를 촉매·구조로 실행    | 환경 catalyst가 전부 대신할 수 있음 |
| 촉매 P    | 복제·대사·수선의 속도 지지  | 희석·분해보다 느리면 계통 소실        |
| 에너지 E   | 비평형 반응과 전구체 재공급  | 단발 연료만으로 반복세대 불가         |
| 폐쇄 C    | 딸에서 전체 실행그래프 재구성 | 일부 성분만 복제되어도 전체는 붕괴      |

I(X\_parent;X\_offspring)>0, Var(w|X)>0, R\_life=2Kfᴸ>1 (68)

첫 조건은 유전되는 기억, 둘째는 그 기억에 따른 차등 증식, 셋째는 기능적 후손의 초임계 지속을 요구한다. 따라서 최초 생명의 임계점은 특정 분자 하나가 처음 생긴 순간보다 기억–실행–복구–경계 재생산–선택이 하나의 반복 가능한 계통으로 닫힌 순간이다. 이는 정확한 최초 서열·장소·경로를 복원하는 역사명제가 아니라 합성 원시세포가 통과해야 할 운영적 시험이다.

### V–X 통합 전이식

X\_g₊₁ = F(X\_g,u\_g;G)+ξ\_g (69)

Life V는 F의 기억 고유모드와 층간 전달을 측정하고, VI는 입력 u의 순서를 바꾸어 연산자의 비가환성을 검정한다. VII는 형성된 상태가 선택으로 집단에서 증폭되는지를 분리하며, VIII은 후보상태를 직접 쓰고 지워 인과성을 시험한다. IX는 상태공간을 조직과 niche로 확장하고, X는 이 기억과 실행그래프가 언제 세대 간 자기폐쇄를 이루는지 판정한다.
