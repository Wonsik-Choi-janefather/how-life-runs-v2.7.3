# 결정실험 재현 프로토콜

## 프로토콜 1. PURE 세대별 자기재생

세대 g의 입력과 g+1의 회수물을 동일한 기준으로 정의한다. seed 양, 외부 보충물, 정제손실, 새로 합성된 단백질과 잔존 입력단백질의 구분법을 실험 전에 고정한다. 비리보솜 단백질 총질량, 개별 구성요소의 화학량론, 농도보정 번역활성과 필수 보조계의 잔존량을 동시에 측정한다.

최소 세 번의 동등 이전에서 R\_mass,nr과 기능비를 세대별로 보고한다. 리보솜, rRNA, tRNA, DNA 복제, 에너지와 경계를 외부에서 보충했다면 각각 장부에 표시한다. 질량비 또는 기능비가 반복적으로 1 아래이면 비퇴행적 자기재생 주장을 기각하고, 일부 구성요소만 통과하면 부분폐쇄로 판정한다.

> 판정 원칙 좁은 운영문턱의 통과를 더 강한 자율성·인과성 주장으로 자동 승격하지 않는다.

## 프로토콜 2. Syn3A 모세포-두 딸세포 분배

한 모세포를 시간영상으로 추적하고 분열 뒤 두 딸세포를 모두 회수한다. 분열 직전 모세포의 분자총량과 분열 직후 두 딸의 부피, 리보솜, RNA 중합효소, degradosome, 막단백질과 저복제수 필수복합체를 같은 검출보정 아래 계수한다. 한쪽 딸만 선택하거나 생존한 딸만 남기는 분석은 허용하지 않는다.

분자군별 D\_x를 계산하고 무편향 이항, 부피비례, 공간국소화 모형을 표본 밖 계보에서 비교한다. 검출효율, DNA 배제, 세포주기와 기하를 통제한 뒤에도 방향성 편향이 반복되면 이항 귀무모형을 기각한다. 분배오차와 이후 성장·분열 성공을 연결해 각 필수분자군의 phi 문턱을 추정한다.

> 판정 원칙 좁은 운영문턱의 통과를 더 강한 자율성·인과성 주장으로 자동 승격하지 않는다.

## 프로토콜 3. 합성 프로토셀 자율계통

단일 구획에서 시작해 최소 세 세대 동안 유전체 복제, 번역, 에너지 재생, 막 성장과 분열을 같은 lineage로 추적한다. 각 세대에 공급한 feeder, 막재료, 리보솜, 효소와 에너지기질을 정량하고 시스템 내부에서 합성·재생된 양과 구분한다. 완전 유전체 보존율과 기능을 가진 후손 수를 함께 기록한다.

외부 물질교체를 단계적으로 줄이며 R\_life와 자율성 지수를 동시에 평가한다. 세대수만 통과하고 번역기 또는 에너지가 외부공급에 의존하면 지속성 PASS, 자율폐쇄 NOT ESTABLISHED로 판정한다. 필수모듈이 같은 계통에서 재생되고 R\_life>1이 반복되어야 최초 생명의 강한 운영문턱을 통과한다.

> 판정 원칙 좁은 운영문턱의 통과를 더 강한 자율성·인과성 주장으로 자동 승격하지 않는다.

## 프로토콜 4. LARRY 계보 잔재항

개입 전 단일세포 상태와 barcode를 측정하고, 시간경과 뒤 같은 clone의 RNA·단백질·기능을 연결한다. 세포 단위가 아니라 개체, 배치와 계보를 통째로 홀드아웃한다. 표준 마르코프모형, 현재상태 전용모형, clone 빈도 전용모형과 WRRA 잔재모형을 동일한 전처리와 손실함수로 비교한다.

잔재항은 현재 상태, 세포주기, batch, guide 효율과 생존자 선택을 통제한 뒤에도 외부 계보의 미래상태 예측을 개선해야 한다. 개선이 없으면 독립 잔재항을 제거한다. 원자료 접근이 불완전하면 대체자료의 결과를 LARRY 직접검증으로 표기하지 않고 예비감사로 남긴다.

> 판정 원칙 좁은 운영문턱의 통과를 더 강한 자율성·인과성 주장으로 자동 승격하지 않는다.

## 프로토콜 5. G-T-W 여섯 순열

동일한 세포배경에서 G, T, W의 여섯 순열을 모두 시행한다. 각 연산의 실제 세포내 작용량, 노출시간, 간격, 세척, 독성, 세포주기와 초기상태를 맞춘다. gate 접근성, 전사변환, 안정표지, 단백질과 기능을 각 단계에서 측정하고 조작 제거 뒤 최소 세 번 분열까지 추적한다.

사전 지정한 주평가량은 최종 기억, 기능과 경쟁순열 대비 GTW 격차다. 실현 AUC와 생존자 구성을 보정한 뒤 GTW가 반복적으로 우월하면 비가환 예측을 지지한다. 순열차이가 사라지거나 다른 순열이 안정적으로 우월하면 현재 WRRA GTW 우선가설을 기각하거나 수정한다.

> 판정 원칙 좁은 운영문턱의 통과를 더 강한 자율성·인과성 주장으로 자동 승격하지 않는다.

## 프로토콜 6. write-erase-rewrite

같은 유전자좌에서 표지를 쓰고, 충분히 세척한 뒤 삭제하고, 다시 쓰는 가역조작을 시행한다. 비표적 guide, 촉매불활성 effector, sham, 독성 및 off-target 대조를 포함한다. 각 단계에서 표지, 접근성, RNA, 단백질, 기능, 생존과 clone 구성을 측정한다.

기능적 인과성은 write에서의 방향성 변화, erase에서의 역전, rewrite에서의 rescue와 최소 세 분열 뒤 지속이 함께 나타날 때 지지한다. 표지만 가역하고 기능이 움직이지 않거나 clone 선택으로 결과가 설명되면 해당 표지의 인과적 기억 주장을 철회한다. 결과와 무관하게 분석코드, 제외기준과 주평가량을 공개한다.

> 판정 원칙 좁은 운영문턱의 통과를 더 강한 자율성·인과성 주장으로 자동 승격하지 않는다.
