# LARRY 계보 정답을 포함한 EPI Clone 자료의 독립 감사

## 통합 Seurat 객체의 무결성과 분석 준비도 및 후성유전 기억의 해석 경계

최원식 · 최정인 | Wonsik Choi · Jeongin Choi

Independent Researchers, Republic of Korea

교신저자 Wonsik Choi: janefather@gmail.com | Jeongin Choi: cjeongin024@gmail.com

연구보고서 v0.1 · 2026년 10월 26일 · 공개 기술논문이며 학술지 심사 완료를 의미하지 않는다.

## 초록

후성유전 클론 추론을 독립적으로 검증하려면 메틸화 행렬과 독립 계보 표지의 세포별 연결이 필요하다. 우리는 EPI-Clone M.1–M.3의 공개 통합 Seurat 객체를 전체 다운로드하고 파일 해시, 내부 행렬, 세포 식별자, LARRY 바코드와 클론 크기를 검사했다. 파일은 173,210,114바이트이며 Figshare의 MD5와 일치했다. 객체에는 28,782개 세포, 453개 메틸화 특성과 20개 항체 특성이 포함되었다. 14,396개 세포가 527개 LARRY 바코드에 연결되었고, 모든 바코드에서 기록된 LARRYSize와 직접 집계한 세포 수가 일치했다. M.1과 M.2의 표지 보유율은 각각 64.26%, 69.31%였으며 M.3에는 LARRY 표지가 없었다. 항체 행렬의 575,640개 원소 중 415,365개는 비유한 값이므로 전 세포에 대한 완전한 단백질 관측으로 간주할 수 없었다. 이 결과는 독립 재분석의 입력 조건을 확보하지만 EPI-Clone 성능 재현이나 인과적 기억의 증거를 대신하지 않는다. 우리는 자료 감사, 계보 연관성, 시간적 유지 및 인과적 기억을 구분하는 후속 검증 계획을 제시한다.

## 1 연구 배경과 목적

Scherer 등은 메틸화와 계보 표지를 함께 사용하는 EPI-Clone 연구를 발표했다[1]. 해당 연구의 생물학적 발견과 분석법은 원저자들의 성과다. 본 연구의 대상은 그 연구 전체의 재현이 아니라, 공개 M.1–M.3 객체가 독립 계보 검증에 필요한 세포별 대응 정보를 실제로 제공하는가이다. GEO 등록번호 GSE282971, Figshare 자료 DOI와 저자 분석 저장소를 구분해 추적했다[2–4].

기존 확인에서 Figshare 다운로드가 HTTP 403을 반환한 것은 이 실행 환경의 접근 관측이다. 2026년 10월 26일 Figshare API가 명시한 공식 ndownloader 경로로 전체 파일을 확보했다. 이는 기존 v2 자료의 접근 가능성을 확인한 사건이며, 자료가 이날 처음 공개되었다거나 원저자가 공개 상태를 변경했다는 증거는 아니다. HTTP 오류만으로 자료 자체의 비공개 여부를 단정하지 않는다.

## 2 자료와 방법

원자료는 Figshare 항목 24204750의 seurat_for_figshare.rds이며 자료 DOI는 10.6084/m9.figshare.24204750.v2다. Figshare 메타데이터의 수정일은 2024년 12월 16일이고 라이선스는 CC BY 4.0이다. 전체 크기와 MD5를 확인한 뒤 SHA256을 추가 계산했다. MD5 일치는 전달 무결성의 검사이며 생물학적 진실성이나 저자 신원을 인증하는 검사는 아니다.

R 실행 환경 대신 Python 3.12.14와 rdata 1.1.0을 사용해 R 직렬화 객체를 파싱했다. Seurat와 dgCMatrix 등 전용 생성자가 없는 클래스는 속성을 가진 namespace로 보존되었다. 경고를 결과 파일에 남기고 각 희소 행렬의 차원, 열 포인터, 행 인덱스 범위와 세포 이름 순서를 검사했다. 이 절차는 저장 구조의 검사이며 R Seurat 함수를 실행한 검증은 아니다.

메타데이터 인덱스의 유일성, 필수 열의 존재, LARRY와 LARRYSize의 결측 위치 일치, 바코드별 크기의 불변성과 직접 집계값의 일치를 검사했다. 각 바코드의 관측 크기는 해당 바코드와 연결된 메타데이터 행 수로 정의했다. 별도 추출 경로로 변환 전 파싱 객체의 LARRY 문자열을 직접 세어 표지 세포 수와 고유 바코드 수를 대조했다. 두 경로는 동일한 파일과 파서에 의존하므로 외부 연구팀의 독립 재현으로 부르지 않는다.

결측 LARRY를 하나의 클론으로 묶지 않았고 메타데이터에 없는 계보를 추정해 채우지 않았다. 항체 행렬은 유한 원소 수와 세포별 유한 관측 유무를 실험별로 집계했다. 비유한 값이 실제 미측정, 전처리 또는 변환 중 어느 단계에서 생겼는지는 이번 감사에서 판정하지 않았다.

## 3 결과

전체 파일 크기는 173,210,114바이트였고 MD5는 0cc0bc53add7acb3aee39c673ff8adba였다. SHA256은 d321321b7b3e9fddd038f7707ce5d0d6039c758efe2100c6f2baef01be42c2d1이다. 이는 내려받은 파일의 재식별에 사용할 수 있다.

메타데이터는 28,782행 10열이며 세포 ID는 모두 고유했다. DNAm과 integrated의 data 슬롯은 각각 453 × 28,782였고 AB의 data 슬롯은 20 × 28,782였다. integrated의 counts 슬롯은 0 × 0으로 비어 있었다. PCA는 28,782 × 30, UMAP은 28,782 × 2였다. 검사한 행렬과 임베딩의 세포 순서는 메타데이터와 일치했다. 이 검사에서 오류가 없다는 사실은 배치 보정이나 메틸화 전처리의 생물학적 타당성을 자동으로 보증하지 않는다.

M.1 주 실험은 13,885개 세포 중 8,923개에 LARRY 표지가 있었고 367개 바코드가 관측되었다. M.2 반복 실험은 7,896개 중 5,473개 세포와 160개 바코드였다. M.3는 7,001개 세포이며 LARRY 표지가 없었다. 따라서 전체 28,782개 세포 모두를 LARRY 정답이 있는 표본으로 평가하면 안 된다. 결측 표지가 있는 세포를 제외한 결과는 표지 보유 하위집합에 대한 결과다.

표지 세포 14,396개와 바코드 527개는 변환 전 문자열 추출과 변환 후 DataFrame 집계에서 일치했다. 527개 바코드 모두 LARRYSize가 바코드 안에서 일정했고 관측 세포 수와 정확히 같았다. 이 일치는 메타데이터의 내부 일관성을 보여준다. 독립 실험으로 실제 클론 크기를 다시 측정한 것은 아니며, 데이터 생성 시 크기를 같은 표로 계산했다면 기대되는 일치일 수 있다.

527개 바코드 중 276개는 둘 이상의 CellType에, 216개는 둘 이상의 ProcessingBatch에 나타났다. 이는 저장된 주석에 대한 기술통계다. 같은 바코드가 여러 세포형에 있다는 사실만으로 다분화능, 전달 방향 또는 환경과 무관한 기억을 확정할 수 없다. 바코드 충돌, 이중세포, 주석 오차와 실험 설계를 후속 검토해야 한다.

AB.data의 전체 575,640개 원소 중 유한 값은 160,275개, 비유한 값은 415,365개였다. M.1에서 항체 유한 값이 하나 이상 있는 세포는 7,217개이며 20종 모두 유한한 세포는 454개였다. M.2는 각각 3,849개와 0개, M.3는 6,980개와 0개였다. 따라서 20종 완전사례만 선택하면 M.1의 일부 세포만 남아 실험 간 비교가 달라진다. 비유한 값을 0 발현으로 치환해서는 안 된다. 이번 결과만으로 결측 발생 원인이나 적절한 대치법을 결정할 수 없다.

## 4 WRRA 감사 구조와 해석 범위

WRRA는 이 책에서 Wonsik Reality-Renderer Architecture를 뜻한다. ‘우주가 최소계산의 원칙 아래 움직일 것’이라는 저자의 직관은 프레임워크의 출발점이며 본 자료가 검증하는 생물학적 가설 자체는 아니다. 여기서는 동결된 코어를 변경하거나 우주론을 입증하지 않고 입력, 변환, 관측 출력과 중단 조건을 분리하는 감사 프로파일로 적용한다.

입력은 고정 해시의 객체와 원저자 메타데이터다. 변환은 ID 정렬, 표지 보유 하위집합 정의, 바코드 집계와 행렬 유효성 검사다. 출력은 세포별 계보 대응, 실험별 분모, 결측 장부와 구조 검사 결과다. 파일 불일치, 중복 ID, 잘못된 열 순서 또는 클론 크기 불일치는 해당 감사를 중단시킨다. LARRY가 없는 세포는 정답 평가에서 OPEN으로 두며 생물학적 음성으로 처리하지 않는다.

WRRA의 이번 기여는 판단 경계를 추적 가능하게 만든 감사 설계와 실행 코드다. 일반적인 데이터 품질 검사보다 예측 성능이나 효율이 우수하다는 비교는 수행하지 않았다. 따라서 WRRA만이 이 감사를 가능하게 한다거나 새로운 생명 법칙을 입증했다고 주장하지 않는다.

## 5 후속 성능 재현과 기억 검증 계획

첫 단계는 원저자 R 환경과 버전을 복원해 원래의 표본 포함 조건, 정적 CpG 선택, 클론 크기 분모, 밀도 기준과 군집 방법을 추적하는 것이다. 분모를 확인하지 않은 채 표지 세포 수나 전체 세포 수 중 하나를 선택해 0.25% 확장 기준을 적용하지 않는다. 이후 M.1에서 설정한 조건을 고정하고 M.2에 적용한다. ARI와 AUC는 실제 계산 결과가 생긴 뒤에만 원논문 수치와 비교한다.

두 번째는 세포형·배치·관측량을 조건으로 한 바코드 순열, 정적 CpG 선택의 누출 검사, 표본 수 민감도 및 클론 단위 재표집이다. 같은 클론의 세포를 훈련과 검증에 나누어 넣으면 새 계보 일반화처럼 보일 수 있으므로 새 계보 예측을 주장할 때는 클론 단위 분리를 사용한다. M.2는 생물학적 반복이지만 이미 모든 자료를 탐색했으므로 본 계획을 사전등록 또는 완전히 눈가림된 전향 검증이라고 부르지 않는다.

세 번째는 책 18장의 시간과 세대 구분이다. 공유 LARRY는 클론 소속이며 전체 모세포–딸세포 분열나무가 아니다. Pseudotime도 실제 경과시간이나 정확한 분열 세대수가 아니다. 이 객체만으로 세대당 기억 반감기, 층간 전달행렬, 자매세포 공분산과 전달 방향을 식별할 수 없다. 이러한 항은 시간해상도 계보 추적과 적절한 다층 관측이 추가될 때 검증한다.

마지막으로 인과적 기억을 주장하려면 계보 정보를 보존한 write–erase–rewrite, 적절한 대조군, 기능적 rescue와 교란 후 추적이 필요하다. 정적 CpG의 클론 연관성은 이런 개입 결과를 대신하지 않는다. 본 v0.1에서는 성능 재현, 교란 통제와 인과 검증을 모두 미완료로 남긴다.

## 6 결론

공개 Seurat 객체에서 독립 클론 재분석을 시작하는 데 필요한 메틸화 행렬과 세포별 LARRY 대응을 확보했다. 현재 확정된 성과는 파일 무결성, 구조 정렬, 표지 분모와 클론 크기의 내부 일관성 및 항체 비유한 값의 범위다. 이는 기존 책의 ‘자료 접근 불가’ 경계를 좁히지만 후성유전 기억의 인과성이나 WRRA 고유 생물학의 독립 실증을 확정하지 않는다.

## 자료와 코드 및 연구윤리

원자료와 생물학적 실험의 기여는 Scherer 등에게 있다. 자료 재배포 조건은 원자료 CC BY 4.0을 따른다. 파생 세포 계보표와 바코드 요약은 원 ID를 유지한 추출물이며 새 실험 정답표가 아니다. 공개 패키지의 audit.py는 audit_results.json, raw_parser_check.json, cell_lineage.jsonl과 clone_summary.jsonl을 재생성한다. 원래의 173 MB RDS는 중복 배포하지 않고 DOI와 공식 다운로드 경로를 제공한다.

새 사람·동물 실험은 수행하지 않았고 기존 공개 마우스 자료만 분석했다. 외부 연구비와 이해상충은 없다. 원고 구성과 코드 작성에 생성형 AI를 활용했다. 이 문서의 계산 감사는 외부 동료심사나 원저자의 승인으로 표시하지 않는다. 새 논문 DOI는 아직 발급되지 않았으며 아래 DOI는 인용 원자료와 원논문의 식별자다.
